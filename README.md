Ultra-High-Density EMG Electrode Array
Development of an ultra-high-density electrode array for myoelectric signal acquisition and analysis, with a target of up to 512 electrodes spaced 5 mm apart. 
This project explores the use of a dense microneedle electrode array to support the evaluation of electromyography (EMG) signal analysis methods. Its motivating application is the control of hand prostheses using electrical signals generated by muscles.
The project addresses the limited electrode count and density highlighted in the project presentation, with the aim of providing a platform for more detailed analysis of muscle activity.

Objectives
- Develop an ultra-high-density electrode array for myoelectric signal acquisition.
- Evaluate and validate the performance of myoelectric signal analysis algorithms.
- Investigate EMG decomposition methods for studying motor unit activity.

Target Specifications
- Electrode count:	Up to 512
- Electrode: spacing	5 mm
- Electrode interface:	Microneedles at each electrode (23 microneedles per electrode)
- Recorded signals:	EMG
- Analysis focus: Algorithm evaluation and motor unit decomposition

Potential Applications
- Myoelectric hand prosthesis control.
- Muscle rehabilitation.
- Research supporting neurological disease diagnosis.

Files Architecture
- Archive: Old files
- Code: FPGA Verilog files, C++ PC application for collecting data and Matlab code for motor unit decomposition
- Presentations: Journal club, progess meeting and project summary
- Template Project Folder: Template used for altium projects
- UHDEMG: Electronic and mechanical files

PCB projects are on UHDEMG\01 - SCHEMAS ET PCB\99 - WORKING COPY
PCB Projects:
- DB_Panel: PCB panel of FPGA_DB and Electrode_Breakout
- Electrode_Breakout: PCB that connect to the electrode with headers on it.
- FPGA_DB: FPGA breakout board. Used to connect the FPGA to the INTAN modules boards
- RHD2132_64CH: INTAN modules to sample raw EMG data. Since the RHD2164 is not available, 2x RHD2132 are used in parallel to replace it. Up to 8 boards can be used at the same time to reach up to 512 electrodes.
- Microneedle_Patch: Flexible circuit board where microneedles are installed. 32 electrodes per FPC.
- Microneedle_Patch_Mirrored: Same as Microneedle_Patch, but the tail goes the other way, allowing to connect 64 electrodes to one RHD2132_64CH board.
